# 身份标识生成器

给测试工程师用的**身份标识号码批量生成 + 合规校验工具**。覆盖个人证件与单位证件共 6 类号码，生成结果全部经过内置校验器实时复核。

- **单文件、零依赖、可离线** —— 双击 HTML 就能用，不联网、不上传任何数据
- **生成即校验** —— 每条号码写入界面前先过一遍校验器，合规 / 提示 / 未通过三态标注
- 内置 **527 个区县级 + 369 个地市级**行政区划码，号码不是随手拼的随机串
- 历史 / 台账保存在浏览器 `localStorage`（纯本地）

## 支持的证件类型与规则

| 类型 | 规则 |
|---|---|
| 公民身份证号码 | 18 位；前 17 位数字，第 18 位数字或 `X`；第 7-14 位出生日期落在 `19010101`–`20991231` 且日期真实；校验位按 GB 11643-1999 |
| 外国人永久居留身份证 | 18 位；首位固定 `9`；第 2-3 位首次申领地省级代码（GB/T 2260）；第 4-6 位国家/地区代码（GB/T 2659.1 / ISO 3166-1 数字码，无国籍 `000`）；第 7-14 位出生日期；第 15-17 位顺序码（第 17 位奇男偶女）；第 18 位 MOD 11-2 校验码（数字或 `X`）。旧版 15 位（3 位字母国籍 + 12 位数字）宽松判定为提示 |
| 护照证件号码 | 最多 12 位，前 3 位为国籍代码（ISO 3166-1 alpha-3）；另支持中国护照实际形态：`E`+8 数字、`E`+字母+7 数字、`G`/`P`/`S`/`D`+8 数字、`PE`/`SE`/`DE`+7 数字 |
| 港澳居民来往内地通行证 | 9 位（`H`/`M` + 8 位数字）或 11 位（`H`/`M` + 10 位数字） |
| 台湾居民来往大陆通行证 | 8 位纯数字；或 10-14 位（前 10 位数字，后缀 3 位为 `(字母)`、4 位为 `(两位数字)`） |
| 统一社会信用代码 | 18 位，31 字符集（不含 `I` `O` `Z` `S` `V`）；第 1-2 位登记管理部门 + 机构类别有效组合；第 3-8 位行政区划码；第 9-17 位组织机构代码（GB 11714）；第 18 位校验码按 GB 32100-2015 |

完整的规则条文、校验算法与权威依据见 [docs/编码规则依据.md](docs/编码规则依据.md)。

## 关于「主体标识码含字母」

GB 32100-2015 规定第 9-17 位按 GB 11714 编码（8 位数字 + 1 位校验位）。但真实在册企业的代码里确实存在字母，例如 `91350100M000100Y43` 的主体标识码是 `M000100Y4`。

因此工具给两种模式：

- **严格模式** —— 8 位数字 + GB 11714 校验位，符合国标原文
- **扩展模式** —— 31 字符集随机，贴合真实库的形态

校验器对含字母的主体标识码**降级为「提示」而不是判负**，避免真实代码被误杀。

## 校验结论三级

| 状态 | 含义 |
|---|---|
| ✓ 通过 | 完全合规 |
| ! 提示 | 结构合规，但真实性存疑（如行政区划码未收录、台胞证 11/12 位后缀形态规则未明确） |
| ✕ 未通过 | 结构不满足规则，附具体失败项 |

## 自检脚本

仓库里的 `算法自检.js` 会从 HTML 中抽取算法内核，用 Node 独立复跑验证：

```bash
node 算法自检.js                # 校验完整版
node 算法自检.js index.html     # 校验极简版
```

覆盖：每类证件 2 万条随机生成 + 自校验、已知真实样例判通过（含永居证官方样例 `932682198501010017` / `911124198108030024`）、29 条故意非法号码判负、行政区划码收录率、页面内联脚本语法。当前 **114 项全部通过**。
