# 编码规则依据

本文档列出工具实现的全部规则条文与权威来源，便于评审时逐条对照。

## 一、公民身份证号码

依据：**GB 11643-1999《公民身份号码》**

| 位置 | 含义 | 规则 |
|---|---|---|
| 1-6 | 行政区划码 | 按 GB/T 2260，使用**区县级**代码（如 `440305` 深圳市南山区） |
| 7-14 | 出生日期码 | `YYYYMMDD`，须在 `19010101`–`20991231` 之间且日期真实存在（含闰年 2 月 29 日判断） |
| 15-17 | 顺序码 | 同一区划同日出生者的顺序号；第 17 位**奇数为男、偶数为女** |
| 18 | 校验码 | 按 GB 11643-1999 附录计算 |

校验位算法：

```
加权因子 W = [7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2]
sum = Σ( 第 i 位数字 × W[i] )        i = 1..17
校验码 = "10X98765432"[ sum mod 11 ]
```

长度必须为 18 位；前 17 位为数字，第 18 位可为数字或字母 `X` / `x`。

## 二、外国人永久居留身份证（新版"五星卡"）

依据：**国家移民管理局《外国人永久居留身份证技术规范》（4.6.7 号码构成）**、《新版外国人永久居留身份证适配性改造要点》（2023-12-01 启用）、GB/T 2260、GB/T 2659.1、GB/T 7408、GB/T 17710

### 新版 18 位号码结构

| 位置 | 含义 | 规则 |
|---|---|---|
| 1 | 身份标识码 | **固定为 "9"**（外国人标识；公民身份号码首位按省级地址码排序为 1-8，可据此区分中外人员、识别证件类型） |
| 2-3 | 首次申领地代码 | 省、自治区、直辖市行政区划数字代码**前两位**（GB/T 2260，如 11 北京、32 江苏、44 广东） |
| 4-6 | 国家/地区代码 | GB/T 2659.1（等同 ISO 3166-1 **数字**代码，如德国 `276`、法国 `250`、加拿大 `124`、沙特 `682`）；**无国籍编为 `000`** |
| 7-14 | 出生日期码 | `YYYYMMDD`（GB/T 7408），与公民身份号码口径一致 |
| 15-17 | 顺序码 | 从 `001` 开始；**第 17 位奇数分配给男性、偶数分配给女性** |
| 18 | 校验码 | GB/T 17710—2008 **MOD 11-2**，与公民身份号码校验方式相同（数字或 `X`） |

官方样例（《适配性改造要点》表 1）：

- `932682198501010017` —— 1985-01-01 出生的沙特阿拉伯男性，在江苏（32）首次申领
- `911124198108030024` —— 1981-08-03 出生的加拿大（124）女性，在北京（11）申领，顺序码 002，校验码 4

### 旧版 15 位号码（兼容）

既往版本（外国人永久居留证 / 2017 版永居证）为 **15 位：3 位拉丁字母国籍代码 + 12 位数字**（如 `CAN`…）。新版启用后旧版在有效期内仍可正常使用，证面加注原号码。旧版无 MOD 11-2 校验位，工具按宽松规则判定为「提示」，不核验校验位。

> 注意：网上流传的"前六位为地址码"说法与官方规范不符 —— 申领地代码只占第 2-3 位（省级前两位），第 4-6 位是国家/地区代码。

## 三、护照证件号码

依据：**国家移民管理局《出入境证件简明手册》**、ICAO Doc 9303

### 通用规则（工具默认）

- 最多 **12 位**
- 前 **3 位为国籍代码**（ISO 3166-1 alpha-3，如 `CHN`、`USA`、`HKG`、`MAC`、`TWN`）
- 其后为证件序号（字母 / 数字）

### 中国护照实际形态

| 形态 | 说明 | 位数 |
|---|---|---|
| `E` + 8 位数字 | 2012 年起启用的电子普通护照 | 9 |
| `E` + 字母（不含 I、O）+ 7 位数字 | 2017-04-05 起的新规则 | 9 |
| `G` + 8 位数字 | 电子护照启用前的旧版普通护照 | 9 |
| `PE` / `SE` / `DE` + 7 位数字 | 公务普通 / 公务 / 外交**电子**护照 | 9 |
| `P` / `S` / `D` + 8 位数字 | 公务普通 / 公务 / 外交**传统本式**护照 | 9 |

护照号码**非终身唯一**，换发或补发会重新生成；同一人可同时持有多本不同号码的护照。

## 四、港澳居民来往内地通行证

依据：**国家移民管理局《出入境证件简明手册》**

- 长度必须为 **9 位**或 **11 位**
- 第 1 位为字母 **`H`**（首次申请地在香港）或 **`M`**（首次申请地在澳门）
- 其后 **8 位或 10 位必须为数字**

即：`H`/`M` + 8 位数字（9 位），或 `H`/`M` + 10 位数字（11 位）。号码为**终身唯一号**。

> 证件正面「换证次数」是独立的 2 位数栏目，**不属于号码本体**，工具不将其计入。

## 五、台湾居民来往大陆通行证

依据：**国家移民管理局《出入境证件简明手册》**

- 长度必须为 **8 位**或 **10-14 位**
- 8 位证件必须为 **8 位数字**（终身号）
- 10-14 位证件：**前 10 位必须为数字**
  - 后缀 3 位 → 应为 `(字母)` 形式
  - 后缀 4 位 → 应为 `(两位数字)` 形式

10 位纯数字号码中，前 8 位为终身号，后 2 位为**签发次数**。

> 11 / 12 位的后缀形态在规则中未明确。工具按「前 10 位数字 + 1~2 位数字（签发次数）」宽松判定，并在结果中标注说明。

## 六、统一社会信用代码

依据：**GB 32100-2015《法人和其他组织统一社会信用代码编码规则》及其国家标准第 1 号修改单**、GB 11714、GB/T 17710、GB/T 2260

### 结构

| 位置 | 含义 | 规则 |
|---|---|---|
| 1 | 登记管理部门代码 | 见下表 |
| 2 | 机构类别代码 | 须与第 1 位构成表 3 中的**有效组合** |
| 3-8 | 登记管理机关行政区划码 | 6 位数字，按 GB/T 2260（实际多用地市级码，如 `440300` 深圳市） |
| 9-17 | 主体标识码（组织机构代码） | 按 GB 11714 |
| 18 | 校验码 | 按 GB/T 17710 |

### 第 9-17 位：组织机构代码（GB 11714）

8 位数字本体码 + 1 位校验码（数字或 `X`）：

```
加权因子 W = [3, 7, 9, 10, 5, 8, 4, 2]
sum = Σ( 第 i 位数字 × W[i] )        i = 1..8
c = 11 - ( sum mod 11 )
c = 11 → 0      c = 10 → X      否则 → c
```

### 第 18 位：校验码（GB/T 17710）

```
加权因子 W = [1, 3, 9, 27, 19, 26, 16, 17, 20, 29, 25, 13, 8, 24, 10, 30, 28]
idx = 该字符在 31 字符集 "0123456789ABCDEFGHJKLMNPQRTUWXY" 中的下标（0-30）
sum = Σ( idx(第 i 位) × W[i] )      i = 1..17
校验码 = 31 字符集[ (31 - (sum mod 31)) mod 31 ]
```

## 七、关于真实代码的两个已知偏差

1. **主体标识码含字母**：GB 32100-2015 要求第 9-17 位按 GB 11714（纯数字）编码，但真实在册企业存在字母形态，例如 `91350100M000100Y43` 的 `M000100Y4`。工具提供「扩展模式」生成，且校验时降级为提示而非判负。
2. **行政区划码层级**：统一社会信用代码第 3-8 位实际多用**地市级**码（`440300` 深圳市、`350100` 福州市），而身份证前 6 位用**区县级**码（`440305` 南山区）。工具分别为两者准备了独立的区划表。
